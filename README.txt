TRIDENTXMP – samostatné stránky pro GitHub Pages

Soubory:
- index.html: Domů
- servers.html: Servery
- start.html: Jak začít
- shop.html: Shop
- rules.html: Pravidla
- discord.html: Discord
- style.css: společný vzhled

Jak nahrát:
1. Otevři svůj GitHub repozitář.
2. Klikni na Add file → Upload files.
3. Nahraj všechny soubory z této složky (ne samotný ZIP).
4. Klikni na Commit changes.
5. Počkej, až se GitHub Pages aktualizuje.

Poznámka: Vzhled je převzat z dodaného fialového TRIDENTXMP HTML. Odkaz Discord vede na odkaz uvedený v původním souboru.
